# Odin Recipes

Here is my solution for the Project: Recipes in The Odin Project Foundations course.

The first three are recipes I actually know how to cook and can vouch for. The birria tacos are an easy recipe based on [Slow Cooker Birria Tacos by Gina Homolka at Skinnytaste](https://skinnytaste.com/slow-cooker-birria-tacos-recipe).

- Feta Salmon Pasta
- Macaron, inspired by Nick DiGiovanni
- Chicken Alfredo, inspired by @stealth_health_life on TikTok
- Birria Tacos

## Built with

Plain HTML and one shared stylesheet (`styles/style.css`). No frameworks and no build step.

- Responsive layout that works on phones
- Light and dark themes that follow your system setting
- Ingredient checklists made with plain HTML checkboxes, no JavaScript
